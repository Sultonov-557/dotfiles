# Excalibur 0.32 lessons (top-down tile game at /home/sultonov/projects/javascript/game)

- **`onPreUpdate(engine, elapsed)` / scene `postupdate` receive the per-tick DELTA in ms, not a monotonic clock.** Subtracting consecutive `elapsed` values yields ~0 and kills all time-based logic (movement, easing, FPS sampling). Use the value directly: `dt = clamp(elapsed, 0, 50) / 1000`.
- **TileMap-vs-Actor physics is not reliable here** (player walked through `tile.solid` tiles). Solution: opt the player out of physics (`collisionType: CollisionType.PreventCollision`), keep a private movement-velocity model, zero body `vel` each frame (so EulerIntegrator never double-moves), and resolve axis-separated AABB vs tile grid manually via corner probes (`isSolidAt(px, py)`).
- PhysicsSystem integrates velocity for EVERY entity with a MotionComponent regardless of collision type (grep `EulerIntegrator.integrate` in build/dist/excalibur.js).
- Keyboard `isHeld(Keys.D)` works headless (Playwright `keyboard.down('d')` produces `code: 'KeyD'`); the keyboard attaches to `window` (`global.addEventListener('keydown')`).
- Playwright test seam: `window.__game` debug handle in src/main.ts exposes `playerPos/isSolidAt/teleport/cameraZoom/seed` — used by tests/smoke.spec.ts.
- Headless WebGL warnings ("GPU stall due to ReadPixels") are harmless noise.
- Test suite: `npm test` = `tsc && vite build && playwright` (webServer port 5199, reuseExistingServer).

Fix: compute source bounds with `Math.floor(vx0/SCALE)` / `Math.ceil((vx0+WIDTH*wpp)/SCALE)` then clamp, instead of float rect arithmetic. Works at every zoom (zoom 0.02 → world thumbnails to an ~18px blob at the expected anchor).
