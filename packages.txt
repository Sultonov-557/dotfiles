# =============================================================================
# packages.txt - curated package list for this system
#
# One package per line. Comments start with "#"; an inline "# ..." after a
# package name is stripped before install. Blank lines and the boxed section
# titles below are ignored.
#
# How this file is installed (see scripts/run_onchange_install-packages.sh.tmpl
# and scripts/run_onchange_install-aur-packages.sh.tmpl):
#   - Both are chezmoi run_onchange scripts, so they re-run automatically
#     whenever this file's contents change - no manual trigger needed.
#   - Every line is installed via `pacman -S`, EXCEPT the single block that
#     starts at the boxed "AUR" title near the end of this file and runs to
#     EOF - that block is installed via `paru` instead (needed for AUR-only
#     packages). Keeping it last means the block can never be closed early
#     by a following title, so don't add a titled section after it.
#   - CRITICAL: both scripts detect a boxed section title by its box-drawing
#     dash characters, not by "#" alone. Don't reuse that glyph in prose
#     elsewhere in this file, and never let a boxed title lose its leading
#     "#" - either mistake silently breaks the boundary (the AUR block gets
#     skipped entirely, or a stray line gets fed to pacman/paru as a literal
#     package name and install fails with "target not found").
#   - Uncomment a line to add it on next apply; comment one out to stop
#     tracking it (this does not uninstall it).
# =============================================================================
